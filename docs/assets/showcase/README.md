# Documentation demonstrations

These files are generated by the
[showcase recipe](https://github.com/e-south/dense-arrays/tree/main/maintenance/docs/showcase).
The recorded inputs and output hashes are in `receipt.json`.

The README shows the rounded 100-bp loop inline, with a static PNG fallback.
Its delivery URLs select an immutable commit. The docs index uses
the 60-bp workflow still. The constraints guide places that row beside the
upstream/downstream spacing explanation. The original artwork stays with its
author. Regenerate these delivery files through the recipe.
